# Albumcito Facilito — Frontend App

The frontend application for the Albumcito Facilito sticker album experience.

## Agent

For all frontend development work — pages, components, hooks, layouts, API routes, and refactoring — use the **`frontend-architect`** agent. It contains the full project context, stack details, domain vocabulary, file conventions, and skills needed to work in this workspace.

## API

Talks to the backend at `apis/albumcito-facilito-api/` on port 3001. See the root `CLAUDE.md` for shared domain concepts.
